# 同频

同一套聊天网页和 WebSocket 协议，可在 Windows（Radmin VPN 局域网）或 Linux VPS 上运行。

## 本地运行

```bash
npm install
npm start
```

浏览器打开 http://127.0.0.1:8787 ，填写昵称后点连接。用两个浏览器窗口加入同一房间即可验证实时收发。

复制 `.env.example` 为 `.env` 可修改：

- `HOST`：默认 `127.0.0.1`。Radmin 网内给其他电脑用时，改为该虚拟网卡 IP，或 `0.0.0.0` 后用防火墙限制来源。
- `PORT`：默认 `8787`。
- `ROOM_PASSWORD`：云端或半公开部署时务必设置。

## 云端试跑

近期计划优先尝试国内云厂商提供的限时 VPS 试用。当前项目可直接运行在 Linux 云服务器上；试用资格、时长、规格和到期费用以云厂商控制台为准。部署环境变量、端口和消息文件备份注意事项见 [架构与部署备忘](ARCHITECTURE.md)。

网页里的服务器地址示例：

- 本机：`ws://127.0.0.1:8787/ws`
- Radmin 对方电脑：`ws://<虚拟IP>:8787/ws`
- 云端 HTTPS：`wss://你的域名/ws`

LAN 与云端是不同服务实例：账号、房间和消息默认互不同步。
